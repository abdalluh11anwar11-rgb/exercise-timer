# Exercise Timer

Next.js exercise timer app.

## Deploy on Vercel
1. Import this repository into Vercel.
2. Keep the Root Directory as `.`.
3. Vercel should detect Next.js automatically.
4. Build command: `npm run build` (default).
5. No environment variables or database are required.

## Data storage
Workout settings, progress, custom exercises, and music preferences are saved in the browser's local storage on the device. They are not synced between devices or browsers. Use the app's export/backup feature before clearing browser data or changing devices.

## Local development
- `npm install`
- `npm run dev`
